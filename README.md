# Microservices-Project
This project was carried out in a team of six: one team leader, two frontend developers, two backend developers, and one DevOps engineer (me).

Its goal was to learn to work in a group and to apply the software engineering concepts we had studied previously. We set weekly goals and tracked our progress using Jira and burndown charts.

The project consisted of building a microservices-based website hosted on a "cloud", a role filled by the university's servers. We used a variety of technologies, including MicroK8s, Docker, GitLab, Quarkus, and React.

As the DevOps engineer, I was in charge of this "cloud": I configured the firewall, managed the containers and their versions, set up the ingress, and deployed the latest versions. I also created the CI/CD pipeline for every microservice, since each one had its own dedicated repository.
